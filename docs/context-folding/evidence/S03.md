## 2. 预算与选择契约

- 预算使用 `U = min(I ?? C, C - O)`、`T = floor(U * 0.7)`；仅 `E > T` 继续。`C`、显式 `I`、最终 `O` 和协议开销必须是有效安全整数，未知输出预留不按零处理。
- `E` 对实际传输的 messages、wire-visible tool 名称/描述/schema、system 所在位置和协议开销做一次共享 `Token.estimate`。system 契约只能选择 `messages`、`instructions`、`none` 或 `unknown`；进入 messages 时不再传第二份 system 值，instructions 则明确单独计量。可执行 tool closure、未知媒体、访问器、异常对象或不可序列化 schema 使整次请求跳过。
- 候选按 S02 的旧到新顺序选择。正文与固定占位的 JSON 字符串估算差额为单项净收益，`511` 不选、`512` 和 `513` 选择；累计估算达到 `T` 即停止。候选耗尽仍超目标只记录 `overBudget: true`，不删除唯一内容，也不触发摘要或重试。
- 工具 schema、消息、system 位置、模型/runtime identity 或最终输出预留都由本次准备输入提供；共享层没有上次请求的预算或模型缓存。

## 3. 最终 wire 映射与原子投影

两个后续适配器复用 `WireProjectionSnapshot` 契约：分别列出最终 provider 可见的 call 与 result，对每项提供稳定 source ref、最终可见 call ID、顺序和唯一正文路径。共享层要求：

1. call/result source ref 和最终 call ID 均一一对应且全局唯一；碰撞、重复 ref、缺失 result 或重复正文路径整次回退。
2. source/witness 均完整存在于本次最终请求，witness 顺序更晚、未成为任何 source，且最终 wire 正文逐字相等。
3. 请求 identity 的共享指纹必须同时匹配计划捕获值和映射捕获值；模型、runtime、system/messages/tools 或适配器 identity 变化使旧计划失效。
4. witness call ID 先限制为最多 128 UTF-8 bytes，再用 JSON 字符串规则转义后放入唯一固定英文占位；过长或空引用跳过，不解释为指令。
5. 投影先严格深拷贝整个可序列化 request root，再只修改已验证正文路径。所有替换完成后复核 source 占位、witness 全文和原请求全文；任何 clone、路径、写入、共享别名或复核失败都丢弃私有副本并返回同一个原请求对象。

共享层没有 OpenCode AI SDK、Native LLM 或 Core `TextPage` 的具体结构分支；S05/S06 必须从各自最终 wire 生成上述映射，并完成真实宿主正向测试。

## 4. 资源保护与固定上限

资源计数在候选规范化和身份字符串构造之前开始，并在递归扫描、JSON 线化、深拷贝与哈希分桶过程中持续执行。数组在按长度构造任何索引集合之前检查；规范化深度在递归进入时检查；字符串先逐 code unit 计算 UTF-8 bytes，确认预算后才构造规范化或 wire 字符串。超限统一精确跳过为 `work-limit`，不截断、抽样或近似比较。

固定内部上限：

| 维度                               | 上限                       | 行为                                    |
| ---------------------------------- | -------------------------- | --------------------------------------- |
| 每阶段 UTF-8 输入                  | 8 MiB                      | 超限立即 `work-limit`                   |
| 中间字符串累计字符预算             | 64 MiB                     | 防止规范化/JSON 父级拼接放大            |
| steps / candidates / wire mappings | 4,096 / 4,096 / 4,096 each | 在候选字段扫描、映射索引和规范化前检查  |
| 单 fingerprint bucket              | 1,024 entries              | 第 1,025 项跳过整次计划，不降级近似相等 |
| nodes / container items            | 131,072 / 131,072          | 覆盖对象、数组、预算序列化和独立副本    |
| 递归深度                           | 64                         | 进入第 65 层前失败关闭                  |

这些上限是首版内部常量，不是公开配置。输入字节、候选数和强制碰撞桶已实际基准；深度、节点及容器上限通过退化测试验证 fail closed，但本步没有把它们包装成跨硬件性能保证。
