## 1. 范围与结论

本步只新增共享、纯函数式的去重规划策略及 Core 单元/属性测试，不接入 Core runner 或 OpenCode 请求路径，不计算 S03 预算，不生成占位，不投影 wire 请求，不读取存储或调用模型服务。因此本步没有测试环境运行产物，也不把策略层通过误报为产品功能已经启用。

新增文件：

- `packages/core/src/session/context-folding/types.ts`
- `packages/core/src/session/context-folding/policy.ts`
- `packages/core/src/session/context-folding/normalize.ts`
- `packages/core/src/session/context-folding/plan.ts`
- `packages/core/src/session/context-folding/index.ts`
- `packages/core/test/session/context-folding.test.ts`

规划器实现了 S02 固定契约：

- 只允许可信的同 session、同宿主内置 registration/generation 的 `read`、`grep`、`glob` 完成结果；来源、call、message 或 registration 身份不一致时保守排除。
- 附件、动态/未知指令、provider 执行、非完成状态、未知/不完整正文、未知 read 目标、受保护指令文件均不参与 source 或 witness。
- 参数及适配器已验证的非正文字段使用同一严格规范化：递归排序对象键，但保留数组顺序、缺失与 `null`、`-0`、路径、空白、正文和结果外层字段差异；循环、访问器、throwing proxy、稀疏/扩展数组、异常原型、`undefined`、`bigint`、非有限数等失败关闭，不调用 getter。该输入为 S06 的 Core `TextPage` 外层字段比较保留共享契约，但本步不实现适配器。
- 哈希只缩小桶范围；桶内仍比较包含完整参数和完整正文的确定性身份。测试注入强制碰撞，证明不同正文不会合并。
- 每个重复组固定时间上最新的完整候选为 witness；witness 永不进入 source。近期保护从末尾向前扩展，直到同时覆盖至少 4 个完整步骤和 16,000 个估算 tokens；整个步骤及并行兄弟保持完整。
- replacement 按原时间顺序返回，输入不被修改；结构、token 估算或指纹异常时返回固定 skip reason 和空 replacement，不部分提交。
