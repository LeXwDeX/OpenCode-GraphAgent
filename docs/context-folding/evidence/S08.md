## Defect found and corrected

The Native HTTP transport fails the stream with `@opencode-ai/llm`'s classified `LLMError`, while the Session error
adapter previously recognized only AI SDK `APICallError`. A classified Native 413 therefore became `UnknownError`
and skipped overflow recovery. `MessageV2.fromError` now preserves both classified native failures and structured
`provider-error` events; `SessionProcessor` passes those events to the error adapter without replacing them with a
generic `Error`. Unit and full-loop regressions cover both surfaces. The existing rule that an unrelated generic 413
is not automatically a context overflow remains covered and unchanged.
