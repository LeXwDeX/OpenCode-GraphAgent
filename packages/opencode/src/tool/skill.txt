Load a skill when the task matches one listed in the system prompt.

This tool adds the skill's instructions and resources to the conversation. Its output may include workflow guidance and references to scripts or files in the skill directory.

The skill name must match one of the skills listed in your system prompt.

## Parameters

- `name` (REQUIRED): The name of the skill to load.

## Returns

The skill document content (`<skill_content>`) and referenced skill files (`<skill_files>`).
